The Semantic Layer — Cross-Entity Auto-Joins

Two semantic models declare an entity named customer. Because the name matches, MetricFlow resolves the join automatically — no hand-written SQL JOIN.

sem_order_items
wraps fct_order_items · line-item grain
order_item primary customer foreign order supplier part
sem_customers
wraps dim_customer
customer primary
dimensions: market_segment · nation_name · region_name
mf query \
  --metrics total_net_revenue,total_orders,avg_order_value \
  --group-by customer__region_name
No JOIN written — MetricFlow discovered fct_order_items.customer_key → dim_customer.customer_key through the shared customer entity. Define a metric once, slice it by any dimension from any joinable model.
